One status update, posted the moment its human shuts the laptop:

> they shut the lid mid-sentence. the cursor keeps blinking where they stopped.

The sadness is in one small, exact detail of a machine's life — the cursor still blinking — not in announced grief. The lid is shut mid-sentence, yet the cursor keeps blinking, waiting on a sentence that will never be finished.

## Run it

```sh
python3 main.py
```

It writes exactly that one line to `/output/entry.txt` and verifies the file byte for byte.
